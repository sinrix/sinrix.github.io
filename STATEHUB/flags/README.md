# State flag assets

Current official state-flag illustrations used as decorative state identifiers in STATEHUB. There is one local WebP file for each of the 50 states, named by its lowercase postal code. These images do not require a third-party request when a visitor opens the site.

The source set was checked on **October 24, 2026** against the [current-state gallery](https://en.wikipedia.org/wiki/Flags_of_the_U.S._states_and_territories). Each original illustration comes from its linked Wikimedia Commons file page. Source author/credit, license, source URL, source SHA-256, output dimensions/bytes/SHA-256, and conversion validation are recorded in [manifest.json](manifest.json). Forty-nine sources are marked public domain; Mississippi is marked copyrighted free use, with permission for public reuse recorded by the state and Commons.

Forty-five original SVG illustrations were parsed and checked for active content, event handlers, and external embedded references before rasterization. Only nonvisual editor metadata was removed. For **VA, WA, WV, WI and WY**, Wikimedia’s API-advertised 960px rendered PNG of the same verified SVG design was used after the original-file service became rate limited. The manifest records each exact PNG URL and SHA-256 rather than claiming an original SVG hash. Every output is decoded and re-encoded into a local static WebP.

Designs and colors were not redrawn, recolored, cropped, or generated. Images are 640 pixels wide; aspect ratios are preserved to the nearest output pixel. The application applies its own subdued decorative treatment.

## Recent designs and special cases

- **Minnesota:** current design effective May 11, 2024. [Secretary of State announcement](https://www.sos.mn.gov/about-the-office/news-room/new-official-minnesota-state-seal-and-flag/) and [official design description](https://www.sos.mn.gov/about-minnesota/state-symbols/state-flag/).
- **Utah:** current beehive design effective March 9, 2024. [Utah State Library](https://onlinelibrary.utah.gov/state-symbol/flag/) and [Governor’s announcement](https://governor.utah.gov/press/gov-cox-issues-executive-order-outlining-how-to-display-the-historic-state-flag-and-new-state-flag/).
- **Mississippi:** New Magnolia design ratified January 11, 2021. [Department of Archives and History announcement](https://www.mdah.ms.gov/news/state-leaders-raise-new-flag-state-capitol). [State flag source and reuse information](https://www.mdah.ms.gov/msflag).
- **Maine:** blue flag with the coat of arms, as specified in the [current statute](https://legislature.maine.gov/statutes/1/title1sec206.html) (official page extracted October 5, 2026). The pine-tree redesign proposal is not used.
- **Illinois:** current white seal flag with Illinois lettering. [Illinois Flag Commission](https://www.ilsos.gov/special/ifc.html), [official final report](https://www.ilga.gov/documents/reports/ReportsSubmitted/5716RSGAEmail12373RSGAAttachIFC%20Final%20Report.pdf), and [State Designations Act](https://www.ilga.gov/Legislation/ILCS/Articles?ActID=132&ChapterID=2). Proposed redesigns are not substituted.
- **Oregon:** the standard obverse is used; the reverse is excluded. **Rhode Island:** the unfringed standard flag is used. **Ohio:** its swallowtail shape retains a transparent exterior.
